# Dataset

The dataset is not stored in this repository. Download it from Kaggle:

**Data Leakage Detection** by syedmarslanalvi
https://www.kaggle.com/datasets/syedmarslanalvi/data-leakage-detection

Save the file as:

```
data/raw/Data_Leakage_Detection.csv
```

49,500 events, 15 columns. Label column: `Abnormality` (0 = normal, 1 = leakage).
It is the dataset used by Harahap & Hasibuan (2025); the first 15 rows and the summary tables match the paper.
